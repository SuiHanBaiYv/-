# 塔防大战 · Tower Defense

一个纯前端的塔防游戏，零依赖、零外部素材 —— 所有图形由 Canvas 代码绘制，所有音效由 WebAudio 实时合成。

## 运行

直接双击 `index.html` 即可，或起个静态服务器：

```bash
python -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

## 玩法

敌人从左侧「出」进入，沿固定路线走向右侧「入」。在路线沿途建造防御塔把它们全部拦下。

### 防御塔（各 3 级）

| 塔 | 造价 | 定位 | 特点 |
|---|---|---|---|
| 箭塔 | 50 | 单体主力 | 射速快、造价低，前期核心 |
| 炮塔 | 105 | 范围清场 | 溅射伤害，专治成群小兵 |
| 冰塔 | 75 | 控制辅助 | 伤害低但减速，延长其他塔的输出窗口 |
| 电塔 | 150 | 连锁爆发 | 多目标弹射，敌人越密集越强 |

每座塔可升级两次（升到 Lv.3），拆除返还累计投入的 60%。

### 敌人

小兵（普通）/ 疾行者（超快）/ 重甲兵（高血高护甲）/ 首领（每 8、15、16 波）。

**护甲是百分比减伤**，所以重甲兵怕高频低伤（箭塔），不怕低频高伤 —— 电塔和炮塔打它效率偏低。

### 操作

| 操作 | 方式 |
|---|---|
| 选塔 | 快捷键 `1` `2` `3` `4`，或点右侧商店 |
| 放置 | 选中后点空地（路径上不能建） |
| 选中已建塔 | 直接点击 |
| 升级 / 拆除 | 选中后在「防御塔信息」面板操作 |
| 取消 | `ESC` 或鼠标右键 |
| 立即开波 | `空格`（剩余准备时间会折算成额外金币） |
| 暂停 | `P` |
| 变速 | `F`（×1 / ×2 / ×3） |
| 切换索敌优先级 | `T`（最前 / 最后 / 最近） |

### 小技巧

- **拐角处收益最高** —— 敌人在拐弯处减速停留，被多座塔覆盖
- **提前开波换金币** —— 准备阶段每秒额外 +2 金币
- **冰塔是放大器** —— 一座冰塔能让周围所有塔的输出翻倍
- **重甲兵来了补箭塔**，小兵扎堆时上炮塔和电塔

## 规则

- 起始 240 金币、20 点生命
- 共 16 波，撑到最后即胜利
- 敌人漏过终点扣生命，归零即失败
- 得分 = 击杀奖励 ×2 + 波次奖励 + 剩余生命 ×150

最高分存在 `localStorage`。

## 文件结构

```
tower-defense/
├── index.html        页面结构与 UI
├── style.css         浅色主题样式（含响应式）
├── js/
│   ├── config.js     全部数值配置：塔、敌人、波次、经济
│   ├── audio.js      WebAudio 合成音效
│   └── game.js       渲染、主循环、交互逻辑
├── test-e2e.js       端到端测试（CDP 真实鼠标键盘事件）
└── screenshot-*.png  测试自动截图
```

想调平衡性只改 `config.js` 就行，不用碰逻辑代码。

## 测试

```bash
# 需先启动本地服务器
python -m http.server 8899
node test-e2e.js
```
